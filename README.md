# QuadraticDesktop

A Windows application for solving quadratic equations and plotting
function graphs.

## Features

- Solving linear and quadratic equations;
- Displaying roots;
- Plotting a parabola;
- Highlighting roots and vertices on a graph.

## System Requirements

- Windows 10 version 1809 or later;
- 64-bit system;
- Microsoft Edge WebView2 Runtime.

## Download

[Download the latest version](https://github.com/TaylorSumers/QuadraticDesktop/releases/latest)

## Installation

1. Open the latest release page.
2. Download the file `QuadraticDesktop-1.0.2-windows-x64.msix`.
3. Open the file and click "Install".

## Building from source code

Building requires Visual Studio, C++ development components, and the Windows App SDK.

Open `QuadraticDesktop.slnx`, select the `Release | x64` configuration, and build the solution.
